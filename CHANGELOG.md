## [0.0.1] — 2026-06-15

### Added
- `README.md` — project overview, status, tech stack, hard rules
- `PRD.md` — Product Requirements Document (vision, personas, user stories, success metrics, risks, release plan)
- `SRS.md` — Software Requirements Specification (functional requirements FR-AUTH through FR-ADM; non-functional requirements covering performance, scalability, reliability, security, privacy, observability, maintainability, portability, cost, usability, reproducibility, i18n)
- `ARCHITECTURE.md` — full system, data, API, CV pipeline, ML, agent, deployment, security, and monitoring architecture
- `TECH_REVIEW.md` — technology review for all 10 proposed stack items with alternatives, trade-offs, recommendations, and 6 proposed ADRs
- `FOLDER_STRUCTURE.md` — monorepo layout with conventions and gitignore preview
- `ROADMAP.md` — 15-phase development roadmap with objectives, deliverables, dependencies, acceptance criteria, risks, and testing strategy per phase
- `GIT_STRATEGY.md` — binding git rules: hard rules for assistant, identity verification, branching model, commit convention, PR workflow, approval loop, authorship requirements, repository safety
- `FEATURES.md` — innovation backlog: 10 additional features, 5 AI features, 5 ML features, 5 CV features, 5 recruiter-impressive features, 5 startup opportunities, each with complexity, resume impact score, and effort estimate
- `EVALUATION.md` — 10-dimension project scoring (average 8.7/10), weaknesses, risks, missing features, and recommended improvements
- `PROJECT_PROGRESS.md` — live progress tracker with phase status, open ADRs, blockers, risk register, and architecture decision log
- `TODO.md` — open task list by priority (high / medium / low / backlog / done)
- `CHANGELOG.md` — this file

### Notes
- No code written. Planning gate is active.
- Git identity not yet confirmed — see `PROJECT_PROGRESS.md`.
- Six ADRs open — must be resolved before Phase 2 begins.
